---

## 🎯 Project Overview

This repository contains the Power BI report (`yn ecommerce sales.pbix`) and underlying transactional datasets (`Orders.csv` and `Details.csv`) used to track revenue, profit margins, and order volume across product categories, sub-categories, and customer segments. Create interactive dashboard to track and analyze online sales data used complex parameter to drill down in worksheet and customization using filters and slices. created connections, join new tables, calulations to manipulate data and enable user drive parameters for visualizations. Used different types of customized visualiztion (bar chart, pie chart, donut chart, clustered bar chart, scartter chart, line chart, area chart,map, slicers, etc).
